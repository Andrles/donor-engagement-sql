# SQL-анализ вовлечённости доноров

## Цель проекта

Проанализировать активность доноров, эффективность каналов привлечения и связь бонусной программы с количеством подтверждённых донаций. Результат — рекомендации для команды, отвечающей за удержание и развитие донорской базы.

## Бизнес-вопросы

- В каких регионах сосредоточена аудитория доноров?
- Как менялось число донаций в 2022–2023 годах?
- Какие каналы авторизации связаны с более высокой активностью?
- Как различается активность однократных и повторных доноров?
- Как связана бонусная программа с количеством донаций?

## Данные

Использованы обезличенные данные донорской платформы из трёх таблиц:

- `user_anon_data` — профиль донора, регион, количество подтверждённых донаций и каналы авторизации;
- `donation_anon` — история донаций;
- `user_anon_bonus` — участие в бонусной программе.

Исходные данные не публикуются в репозитории, так как содержат данные учебной базы.

## Инструменты

PostgreSQL, SQL, CTE, `JOIN`, оконные и агрегирующие функции, работа с датами.

## Подготовка данных

В данных обнаружены пропуски регионов и некорректные даты. В запросах они исключаются до расчёта метрик, чтобы аномалии не искажали выводы.

## Ключевые наблюдения

- Наибольшая часть идентифицированных доноров находится в Москве и Санкт-Петербурге.
- Весной наблюдаются пики количества донаций; это полезная точка для планирования коммуникаций.
- Доноры с бонусами в среднем совершают больше подтверждённых донаций, однако это **связь**, а не доказательство причинного эффекта программы.
- Повторные доноры — ключевой сегмент для удержания: их стоит анализировать отдельно по частоте и давности донаций.

## Рекомендации

- Настроить отдельные сценарии удержания для повторных доноров.
- Проверить качество дат и регионов на этапе загрузки данных.
- Запустить A/B-тест бонусной программы, прежде чем делать вывод о её причинном эффекте.
- Оценивать каналы привлечения не только по числу пользователей, но и по повторной активности.
